# Repository rules

## Personal project storage

`Misc/` and everything beneath it are owner-only project storage, not application source code.

- Do not search, inspect, modify, rename, delete, format, refactor, stage, or commit files under `Misc/` unless the owner explicitly asks for a specific file there.
- Exclude `Misc/` from normal repository searches and automated cleanup.
- Preserve all existing modified and untracked files under `Misc/` exactly as they are.
